# 数据科学

Python 数据科学工具栈，用于数据处理、分析和可视化。

## 学习路线

```
NumPy 数组 → Pandas 数据处理 → Matplotlib 可视化 → 数据分析实战
```

## 核心库

### NumPy
- 多维数组对象
- 数学函数库
- 线性代数运算
- 随机数生成

### Pandas
- DataFrame 数据结构
- 数据清洗与预处理
- 数据分组与聚合
- 时间序列分析

### Matplotlib
- 折线图、柱状图、散点图
- 多子图布局
- 样式定制

## 应用场景

- 📊 数据分析
- 📈 数据可视化
- 🔬 科学计算
- 📉 金融分析
- 🧪 实验数据处理
