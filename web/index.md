# Web 框架

Python Web 开发笔记，涵盖 Flask、Django、FastAPI 等主流框架的实战应用。

## 学习路线

```
HTTP 基础 → Flask 入门 → Django 全栈 → FastAPI 现代化 → RESTful API 设计
```

## 章节概览

### 框架入门

- **Flask** - 轻量级 Web 框架，快速构建原型和小型应用
- **Django** - 全栈式框架，自带 ORM、Admin、认证系统
- **FastAPI** - 现代化高性能框架，原生支持异步和类型提示

### 核心主题

- **路由与视图** - URL 映射、请求处理、响应格式
- **模板引擎** - Jinja2 模板、变量渲染、过滤器
- **表单处理** - 数据验证、CSRF 防护、文件上传
- **数据库集成** - ORM 配置、迁移、查询优化
- **用户认证** - 注册登录、Session、JWT、权限管理
- **RESTful API** - 接口设计、序列化、分页、版本控制
- **部署与运维** - WSGI/ASGI、Nginx 反向代理、Docker 容器化

## 技术选型建议

| 场景 | 推荐框架 |
|------|---------|
| 快速原型开发 | Flask |
| 后台管理系统 | Django |
| 高性能 API 服务 | FastAPI |
| 微服务架构 | FastAPI / Flask |
| 全栈项目 | Django |

::: tip 学习建议
1. 先掌握一个框架的核心概念（推荐从 Flask 开始）
2. 理解 HTTP 协议和 Web 开发通用概念
3. 动手完成完整的项目（如博客系统、API 服务）
4. 学习部署流程和性能优化
:::
