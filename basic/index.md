# 基础

Python 基础教程，从零开始学习 Python 编程，涵盖语法、数据类型、函数、面向对象等核心内容。

## 学习路线

```
环境搭建 → 语法基础 → 数据类型 → 控制流 → 函数 → 面向对象 → 标准库
```

## 学习建议

::: tip 循序渐进
1. 按章节顺序学习，不要跳过基础内容
2. 每章配有练习题，务必动手实践
3. 遇到问题先查看**常见问题**章节
4. 完成基础部分后再学习**进阶**和**数据库**
:::

::: warning Python 版本
本教程基于 **Python 3.14**，部分语法在旧版本可能不支持。建议使用 Python 3.10+ 版本学习。
:::
