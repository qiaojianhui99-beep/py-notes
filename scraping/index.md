# 爬虫开发

Python 网络爬虫开发，从基础到实战的完整教程。

## 学习路线

```
Requests → BeautifulSoup → Scrapy 框架 → 反爬虫对策 → 异步爬虫
```

## 核心技术

### 基础工具
- **Requests** - HTTP 请求库
- **BeautifulSoup** - HTML 解析
- **lxml** - 高性能解析器

### 进阶框架
- **Scrapy** - 爬虫框架
- **Selenium** - 动态网页
- **aiohttp** - 异步请求

## 应用场景

- 📰 新闻资讯抓取
- 🛒 电商数据采集
- 📊 数据监控
- 🔍 搜索引擎
- 📈 价格监控

## 注意事项

::: warning 法律与道德
1. 遵守网站 robots.txt
2. 设置合理的请求频率
3. 尊重网站服务条款
4. 不抓取个人隐私信息
5. 商业使用需获得授权
:::
